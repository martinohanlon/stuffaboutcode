**[About](http://www.stuffaboutcode.com/p/adventures-in-minecraft.html#about)**
[Adventures in Minecraft](http://eu.wiley.com/WileyCDA/WileyTitle/productCd-111894691X.html) is a book written especially for 11 - 15 year-olds which will teach you new programming skills while having fun with Minecraft. You will learn how to create your own mods, utilities and games. Written by

myself, [Martin O'Hanlon](https://twitter.com/martinohanlon)

and [David Whale](http://blog.whaleygeek.co.uk/), its a fun way to not only get into programming but also learn how to do amazing things with Minecraft. Be sure to check out the [companion website](http://wiley.com/go/adventuresinminecraft) which has got loads of extra's and video tutorials.

**[Resources](http://www.stuffaboutcode.com/p/adventures-in-minecraft.html#resources)**
 Looking for information, inspirations or ideas, check out these Adventures in Minecraft resources:

- [wiley.com/go/adventuresinminecraft](http://wiley.com/go/adventuresinminecraft) - The Adventures in Minecraft [companion website](http://wiley.com/go/adventuresinminecraft) is a great source of information with goes along with the book, including downloadable starter kits, code files, video tutorials and a bonus chapter.
- [www.stuffaboutcode.com/p/minecraft-api-reference.html](http://www.stuffaboutcode.com/p/minecraft-api-reference.html) - A complete reference for the minecraft api, including block and data types.
- [www.stuffaboutcode.com/p/minecraft.html](http://www.stuffaboutcode.com/p/minecraft.html) - All my minecraft related blogs are here, including all my projects, such as the '[cannon](http://www.stuffaboutcode.com/2013/04/raspberry-pi-minecraft-cannon.html)'.
- [blog.whaleygeek.co.uk/minecraft-pi-with-python](http://blog.whaleygeek.co.uk/minecraft-pi-with-python) - David's awesome Minecraft python flashcard's, great for teachers and learning
