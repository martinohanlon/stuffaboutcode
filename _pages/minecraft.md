![](/assets/img/2013/02/sam_0819.jpg)Minecraft is brilliant, and the Pi edition doubly so, its free and the API is absolutely genius, allowing you to alter the world in real-time. I have used the api to create a load of cools things, from a [real-time clock](http://www.stuffaboutcode.com/2013/02/raspberry-pi-minecraft-analogue-clock.html) to an [operational cannon](http://www.stuffaboutcode.com/2013/04/raspberry-pi-minecraft-cannon.html).

**Install**

[Minecraft - Install](http://www.stuffaboutcode.com/2013/02/raspberry-pi-minecraft-install.html) - how to install Minecraft: Pi edition on you Raspberry Pi

[Minecraft, Canarymod & RaspberryJuice](http://www.stuffaboutcode.com/2014/10/minecraft-raspberryjuice-and-canarymod.html) - using Canarymod and RaspberryJuice to run Minecraft Pi programs on the full version of Minecraft

**Using the API**

[API Tutorial](http://www.stuffaboutcode.com/2013/04/minecraft-pi-edition-api-tutorial.html) - an in-depth view into Minecraft, the concepts, the API and how to program it, great for beginners

[API - The basics](http://www.stuffaboutcode.com/2013/01/raspberry-pi-minecraft-api-basics.html) - an introduction into the Minecraft API, its functions and how to use it, great for those who already understand Minecraft & have some experience of programming

![](/assets/img/2013/04/minecraft-diamondfloor.jpg)[Python API Reference](http://www.stuffaboutcode.com/p/minecraft-api-reference.html) - a detailed description and reference of the api python library - it documents all the functions available and gives example of how to use the library

[MinecraftStuff Extensions](http://www.stuffaboutcode.com/2013/11/coding-shapes-in-minecraft.html) - I have started an extension library for the API to deliver simple functions, currently there is a drawing class for creating shapes and lines.

![](/assets/img/2014/05/minecraftspirals2.jpg)[Minecraft Graphics Turtle](http://www.stuffaboutcode.com/2014/05/minecraft-graphics-turtle.html) - a 3d graphics turtle for minecraft, program it using command like forward, left, right, up, down, penup, pendown, etc

**My Projects**
 Examples of what I have done with Minecraft: Pi Edition and its API

[Hide and Seek](http://www.stuffaboutcode.com/2013/01/raspberry-pi-minecraft-hide-and-seek.html) - a really simple game of hide and seek for Minecraft

![](/assets/img/2013/02/minecraft-bridge.png)[Auto Bridge](http://www.stuffaboutcode.com/2013/02/raspberry-pi-minecraft-auto-bridge.html) - an absolutely brilliant utility (even if I say so myself) which automatically creates a bridge in front of you, no more falling off cliffs, no more having to swim across oceans, the auto bridge allows you to walk straight on

[Massive Analogue Clock](http://www.stuffaboutcode.com/2013/02/raspberry-pi-minecraft-analogue-clock.html) - big enough so you can walk on the arms

![](/assets/img/2013/04/minecraft-snake.jpg)[Snake](http://www.stuffaboutcode.com/2013/03/raspberry-pi-minecraft-snake.html) - the classic game, Snake, built using the Minecraft API

[Create massive 3D models](http://www.stuffaboutcode.com/2013/03/minecraft-pi-edition-create-massive-3d.html) - render obj 3d model files into Minecraft

[Take a stroll around New York](http://www.stuffaboutcode.com/2013/04/minecraft-pi-edition-manhattan-stroll.html) - Manhattan Island rendered in Minecraft

![](/assets/img/2013/03/empirestate.jpg)[Create 3d Models - version 2](http://www.stuffaboutcode.com/2013/04/minecraft-pi-edition-3d-models-version-2.html) - an update to my 3d model to minecraft renderer, so it draw full polygons and has the ability to map materials in the model to blocks in minecraft

[Cannon](http://www.stuffaboutcode.com/2013/04/raspberry-pi-minecraft-cannon.html) - a fully working cannon, lets blow stuff up!

[Turning blocks into Bombs](http://www.stuffaboutcode.com/2013/05/raspberry-pi-minecraft-block-events.html) - an example of how to capture player block hits, when the player hits a block, it flashes for a few seconds then explodes destroying all the blocks around it

![](/assets/img/2013/04/minecraftcannon.jpg)[Piano](http://www.stuffaboutcode.com/2013/06/raspberry-pi-minecraft-piano.html) - hitting certain blocks to make piano notes, ever wanted to here Twinkle Twinkle Little Star played in Minecraft

[Sound effects](http://www.stuffaboutcode.com/2013/06/raspberry-pi-minecraft-sounds-effects.html) - I got bored of Minecraft: Pi Edition not having any sound effects, so I decided to make my own! Footsteps, falling, screaming, jumping, etc

![](/assets/img/2014/11/minecraftmusic.jpg)[Making a Traffic Jam](http://www.stuffaboutcode.com/2013/11/minecraft-coding-traffic-jam.html) - a collection of programs which show how I went from creating a traffic light to simulating a traffic jam
