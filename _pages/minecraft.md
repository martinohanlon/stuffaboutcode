![](/assets/img/2013/02/sam_0819.jpg)Minecraft is brilliant, and the Pi edition doubly so, its free and the API is absolutely genius, allowing you to alter the world in real-time. I have used the api to create a load of cools things, from a [real-time clock](/posts/raspberry-pi-minecraft-analogue-clock/) to an [operational cannon](/posts/raspberry-pi-minecraft-cannon/).

**Install**

[Minecraft - Install](/posts/raspberry-pi-minecraft-install/) - how to install Minecraft: Pi edition on you Raspberry Pi

[Minecraft, Canarymod & RaspberryJuice](/posts/minecraft-raspberryjuice-and-canarymod/) - using Canarymod and RaspberryJuice to run Minecraft Pi programs on the full version of Minecraft

**Using the API**

[API Tutorial](/posts/minecraft-pi-edition-api-tutorial/) - an in-depth view into Minecraft, the concepts, the API and how to program it, great for beginners

[API - The basics](/posts/raspberry-pi-minecraft-api-basics/) - an introduction into the Minecraft API, its functions and how to use it, great for those who already understand Minecraft & have some experience of programming

![](/assets/img/2013/04/minecraft-diamondfloor.jpg)[Python API Reference](/minecraft-api-reference/) - a detailed description and reference of the api python library - it documents all the functions available and gives example of how to use the library

[MinecraftStuff Extensions](/posts/coding-shapes-in-minecraft/) - I have started an extension library for the API to deliver simple functions, currently there is a drawing class for creating shapes and lines.

![](/assets/img/2014/05/minecraftspirals2.jpg)[Minecraft Graphics Turtle](/posts/minecraft-graphics-turtle/) - a 3d graphics turtle for minecraft, program it using command like forward, left, right, up, down, penup, pendown, etc
