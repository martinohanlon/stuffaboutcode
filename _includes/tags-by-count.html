{%- comment -%} Every tag in use, most posts first, as a comma-separated list of slugs. Counts come from site.tags, which Jekyll builds from the posts themselves, so a new tag reaches the sidebar the moment a post uses it and no count is ever maintained by hand. _data/tags.yml is now only a display-name lookup, for the names a slug cannot express -- csharp is "c#", dotnet is ".net". Liquid cannot sort by a number, only asciibetically, so each row is keyed "<99999 minus count, zero-padded> ". Sorting that ascending puts the biggest count first, and leaves equal counts in alphabetical order -- which is how the hand-maintained list was ordered. Capture it and split on ",": {%- capture ordered -%}{%- include tags-by-count.html -%}{%- endcapture -%} {%- assign slugs = ordered | split: "," -%} Then read a count back with `site.tags[slug] | size`. {%- endcomment -%} {%- assign keyed = "" -%} {%- for t in site.tags -%} {%- assign n = t[1] | size -%} {%- assign key = 99999 | minus: n | prepend: "00000" | slice: -5, 5 -%} {%- assign keyed = keyed | append: key | append: " " | append: t[0] | append: "," -%} {%- endfor -%} {%- assign rows = keyed | split: "," | sort -%} {%- for row in rows -%} {{- row | split: " " | last -}} {%- unless forloop.last -%},{%- endunless -%} {%- endfor -%}
